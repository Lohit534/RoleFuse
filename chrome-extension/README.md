# RoleFuse AI - Chrome Extension for 1-Click Job Capture

## How to Install in Google Chrome (30 Seconds)
1. Open Google Chrome and navigate to: `chrome://extensions/`
2. In the top-right corner, toggle **Developer mode** to ON.
3. Click the **Load unpacked** button in the top-left corner.
4. Select this folder (`extension/`).
5. Pin the RoleFuse icon to your Chrome toolbar!

## How to Use
1. Visit any job posting on **LinkedIn**, **Indeed**, **Glassdoor**, or company careers page.
2. Click the **RoleFuse AI** icon in your browser toolbar.
3. Click **"Capture from This Tab"** to auto-extract the job title, company, and description.
4. Click **"Open in Cover Letter Studio"** or **"Tailor Resume with RoleFuse"** to generate your application materials in 1 click!
